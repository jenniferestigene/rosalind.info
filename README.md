## About Rosalind

[Rosalind](https://rosalind.info/) is a free, browser-based platform for learning
bioinformatics through problem solving. Rather than working through a textbook
passively, you solve a sequence of increasingly difficult problems: each one
introduces a biological concept (DNA and RNA processing, sequence alignment,
genome assembly, phylogeny, probability and statistics, and more) alongside the
programming and algorithmic technique needed to solve it. Every submission is
checked automatically against a sample dataset and an expected output, so
progress is immediate and verifiable. The project is a joint effort between UC
San Diego and Saint Petersburg Academic University, and its name is a nod to
[Rosalind Franklin](https://en.wikipedia.org/wiki/Rosalind_Franklin), whose
X-ray diffraction data was central to discovering the structure of DNA.

Problems are grouped into five locations, which roughly increase in difficulty
and specialization:

1. **Python Village** – programming fundamentals for people new to Python.
2. **Bioinformatics Stronghold** – the main track, where you implement the
   algorithms underlying bioinformatics yourself.
3. **Bioinformatics Armory** – the same kinds of problems, but solved using
   existing bioinformatics software and libraries.
4. **Bioinformatics Textbook Track** – exercises paired with *Bioinformatics
   Algorithms: An Active Learning Approach* (Compeau & Pevzner).
5. **Algorithmic Heights** – general algorithms and data structures (sorting,
   graphs, searching) applied to biological data.

## About this repository

I'm using Rosalind to teach myself bioinformatics from the ground up: the
biology, the algorithms, and the programming practice needed to implement
them properly rather than just call a library function. This repository holds
my solutions as I work through the problem sets, organized to mirror
Rosalind's own five locations above.

Each problem below is listed with a link to its original description on
Rosalind and a link to my solution. Problems I haven't solved yet are marked
as such; those links will go live as I publish each solution.
